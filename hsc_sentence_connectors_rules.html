⚡ শর্টকাট কৌশল (Connector Exam Hack)
  • আগের বাক্য এবং পরের বাক্যের মধ্যবর্তী সম্পর্ক পর্যবেক্ষণ করুন (কারণ, ফলাফল, বৈপরীত্য নাকি উদাহরণ?)।
  • যদি দুটি বাক্য পরস্পরের বিপরীত অর্থ প্রকাশ করে, তবে However / But / On the other hand ব্যবহার করুন।
  • যদি প্রথমটি কারণ এবং পরেরটি ফলাফল প্রকাশ করে, তবে Therefore / As a result / So ব্যবহার করুন।
